# CpRE288-Final-Project-S.E.N.T.R.Y
A repository containing programs and scripts utilized for SD-PG2's Final Project for CpRE 288 Fall 2026.

Cloning Instructions:
---------------------

1. Clone this repository into your usual CpRE 288 Workspace Directory
2. On IDEs like Code Composer Studio, it may not detect as a CCS project. If so, manually import the project in the workspace. 
  - If it makes copy of the repo, and that copy is the only one detected by CCS, you can use the copy and link it it to the GitHub repo (Delete the original copied repo folder)
3. In properties, make sure you allow the Pre-set Libraries and Custom Libraries for SD-5 and SD-1 Code to be allowed
